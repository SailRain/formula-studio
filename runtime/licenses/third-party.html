Times New Roman 2.82 original complete package

The fonts come from the complete original Microsoft Core Fonts for the Web package times32.exe, with its original name, bytes, copyright, and trademark notices retained. This site does not serve extracted TTF files. The browser reads the package as data and extracts its four original fonts into memory; it does not execute the EXE, install fonts, edit fonts, or convert their format.

Application source and upstream build materials

The source manifest identifies the runtime versions, complete retained upstream archives, hashes, and build records. The engine recipe rebuilds HarfBuzz 3.2.0, Graphite2 1.3.14, and Xpdf 4.02 from source before building SwiftLaTeX v20022022. Release verification also checks formula output. The MuPDF npm commit matches the official 1.28.1 tag; its complete official source archive includes the WASM bindings, third-party implementations, and build scripts. Bit-for-bit reproduction of historical upstream binaries is not claimed.

SwiftLaTeX and MuPDF retain their AGPL terms. The MIT license for original application code does not remove the requirements applicable to the combined distribution. Source downloads are offered here alongside the runtime, without charge. TeX package works retain their individual licenses and original notices. Formula inputs and exported user documents are not included in these source archives.

The application archive contains this version’s interface, wrappers, build scripts, tests, and notices. Full upstream archives are provided separately in the manifest. Private inputs, user reference PDFs, research outputs, system fonts, caches, and credentials are excluded.
